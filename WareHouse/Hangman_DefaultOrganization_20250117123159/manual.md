# Hangman Game

Welcome to the classic Hangman Game! This application allows you to play the traditional word-guessing game with a simple and intuitive graphical user interface.

## Main Features

- **Random Word Selection**: The game selects a random word from a predefined dictionary for each new game.
- **Limited Attempts**: You have a limited number of attempts (6) to guess the word correctly.
- **Graphical User Interface**: The game features a user-friendly GUI built with Tkinter.
- **Real-time Feedback**: Displays placeholders for the letters, tracks correct and incorrect guesses, and updates the display accordingly.
- **Game Reset**: Easily reset the game to start over with a new word.

## Installation

### Environment Setup

This Hangman Game is developed in Python and requires Python to be installed on your system. The game does not require any external dependencies beyond the standard Python library.

1. **Install Python**: If you haven't already, download and install Python from [python.org](https://www.python.org/downloads/).

2. **Clone the Repository**: Clone the repository containing the Hangman Game code to your local machine.

   ```bash
   git clone <repository-url>
   cd <repository-directory>
   ```

3. **Install Dependencies**: Navigate to the project directory and ensure all dependencies are installed. Since there are no external dependencies, you can skip this step.

## How to Play

1. **Run the Game**: Execute the `main.py` file to start the game.

   ```bash
   python main.py
   ```

2. **Game Interface**: Once the game starts, a window will appear with the following elements:
   - **Word Display**: Shows the current state of the word with placeholders for unguessed letters.
   - **Guess Entry**: A text entry field where you can input your letter guesses.
   - **Guess Button**: Click this button to submit your guess.
   - **Message Display**: Provides feedback on your guesses and the number of attempts left.
   - **Reset Button**: Resets the game to start with a new word.

3. **Making Guesses**: Enter a single letter in the guess entry field and click the "Guess" button. The game will update the display to show correct guesses and track incorrect ones. You have a total of 6 attempts to guess the word.

4. **Winning or Losing**: The game ends when you either guess the word correctly or run out of attempts. A message will display the outcome.

5. **Resetting the Game**: Click the "Reset Game" button to start a new game with a different word.

Enjoy playing the Hangman Game and challenge yourself to guess the words with the fewest attempts possible!
