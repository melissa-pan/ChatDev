## Introduction

The Match-3 Puzzle Game is a classic tile-matching game where players swap adjacent candies to form matches of three or more. Matches are cleared from the board, new candies fall into place, and players earn points for each match. The game continues until there are no more possible moves.

## Installation

To get started with the Match-3 Puzzle Game, you need to install the necessary environment dependencies. Follow the steps below to set up your environment:

### Prerequisites

- Python 3.x installed on your machine.
- `pip` package manager for Python.

### Quick Install

1. Clone the repository or download the source code to your local machine.

2. Navigate to the directory containing the source code.

3. Install the required dependencies using the following command:

   ```bash
   pip install -r requirements.txt
   ```

   This will install the `pygame` library, which is essential for running the game.

## Game Setup

Once you have installed the necessary dependencies, you can set up and run the game by following these steps:

1. Open a terminal or command prompt.

2. Navigate to the directory where the source code is located.

3. Run the game using the following command:

   ```bash
   python main.py
   ```

   This command will launch the game window, and you will be ready to play.

## How to Play

The objective of the Match-3 Puzzle Game is to swap adjacent candies to form horizontal or vertical lines of three or more candies of the same type. Here's how you can play:

1. **Select a Candy**: Click on a candy to select it. The selected candy will be highlighted.

2. **Swap Candies**: Click on an adjacent candy to swap it with the selected candy. If the swap results in a match of three or more candies, the candies will be cleared from the board.

3. **Score Points**: Earn points for each match you create. The more candies you match, the higher your score.

4. **Continue Playing**: The game continues as long as there are possible moves. New candies will fall into place after each match.

## Game Features

- **Intuitive Gameplay**: Easy-to-understand mechanics with simple mouse controls.
- **Dynamic Board Updates**: The board updates automatically after each valid move.
- **Scoring System**: Track your score as you play and aim for the highest score possible.
- **Colorful Graphics**: Enjoy vibrant and colorful candy graphics.

## Troubleshooting

If you encounter any issues while running the game, consider the following troubleshooting tips:

- Ensure that Python and `pygame` are correctly installed on your machine.
- Verify that you are using the correct version of Python (3.x).
- Check for any error messages in the terminal or command prompt and address them accordingly.
- If the game window does not appear, try running the game again or restarting your computer.
