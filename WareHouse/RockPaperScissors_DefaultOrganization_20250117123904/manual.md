# Rock-Paper-Scissors Game User Manual

Welcome to the Rock-Paper-Scissors Game! This user manual will guide you through the installation and usage of the game application. Enjoy playing against the computer in this classic game of chance and strategy.

## Introduction

The Rock-Paper-Scissors Game is a simple yet entertaining application that allows you to play the traditional game against the computer. The game is implemented using Python and features a graphical user interface (GUI) for an interactive experience.

## Main Functions

- **User Choice:** Select between Rock, Paper, or Scissors.
- **Computer Choice:** The computer randomly selects Rock, Paper, or Scissors.
- **Determine Winner:** The game compares the user's choice with the computer's choice to determine the winner based on the classic rules:
  - Rock beats Scissors
  - Scissors beats Paper
  - Paper beats Rock
- **Display Outcome:** The result of each round is displayed on the screen.
- **Replay Option:** After each round, you have the option to play again.

## Installation

### Prerequisites

- Ensure you have Python installed on your system. You can download it from [python.org](https://www.python.org/downloads/).

### Installation Steps

1. **Clone the Repository:**
   - Clone the repository containing the game code to your local machine.

2. **Navigate to the Directory:**
   - Open a terminal or command prompt and navigate to the directory where the game code is located.

3. **Install Dependencies:**
   - The game does not require any external dependencies, so you can skip this step.

## How to Play

1. **Run the Game:**
   - Open a terminal or command prompt.
   - Navigate to the directory where `main.py` is located.
   - Run the command: `python main.py`

2. **Make Your Choice:**
   - A window will appear with three buttons: Rock, Paper, and Scissors.
   - Click on one of the buttons to make your choice.

3. **View the Result:**
   - The game will display the computer's choice and the result of the round.
   - The result will indicate whether you won, lost, or if it was a tie.

4. **Play Again:**
   - Click the "Play Again" button to start a new round.
   - The game will reset, allowing you to make a new choice.
