# UC Berkeley Website Prototype

This user manual provides a comprehensive guide to using the UC Berkeley Website Prototype. It includes an introduction to the main functions of the software, instructions for installing environment dependencies, and guidance on how to use the website.

## Introduction

The UC Berkeley Website Prototype is a modern, responsive landing page designed to showcase the university’s brand elements. It features navigation for major sections such as admissions, academics, and research, as well as a news or events section. The design ensures accessibility and is mobile-friendly, making it easy for users to access information on any device.

## Main Functions

- **Responsive Design**: The website is designed to be responsive, ensuring it looks great on devices of all sizes, from desktops to smartphones.
- **Accessibility**: The website includes ARIA roles and labels to enhance accessibility for users with disabilities.
- **Navigation**: Easy-to-use navigation links to major sections of the website, including Admissions, Academics, and Research.
- **News & Events Section**: A dedicated section for displaying the latest news and events related to UC Berkeley.
- **Brand Elements**: Incorporates UC Berkeley’s brand colors and logo to maintain a consistent brand identity.

## Installation

To set up the environment and run the UC Berkeley Website Prototype, follow these steps:

1. **Clone the Repository**: Clone the project repository to your local machine using Git.
   ```bash
   git clone <repository-url>
   ```

2. **Navigate to the Project Directory**: Change into the project directory.
   ```bash
   cd uc-berkeley-website-prototype
   ```

3. **Install Node.js and npm**: Ensure you have Node.js and npm installed on your machine. You can download them from [nodejs.org](https://nodejs.org/).

4. **Install Dependencies**: Install the necessary dependencies using npm.
   ```bash
   npm install
   ```

5. **Compile SCSS to CSS**: Use the provided script to compile SCSS files to CSS.
   ```bash
   npm run build-css
   ```

## Usage

To run the website locally and view it in your browser, follow these steps:

1. **Start the Development Server**: Use npm to start the development server.
   ```bash
   npm start
   ```

2. **Access the Website**: Open your web browser and navigate to `http://localhost:3000` to view the UC Berkeley Website Prototype.

3. **Explore the Features**: Use the navigation links to explore different sections of the website, including Admissions, Academics, Research, and News & Events.

4. **Responsive Testing**: Resize your browser window or use developer tools to test the website’s responsiveness on different screen sizes.

## Conclusion

The UC Berkeley Website Prototype is a powerful tool for showcasing the university’s offerings in a modern and accessible way. By following this manual, you can easily set up and explore the website’s features. For any further assistance or inquiries, please contact the development team.
