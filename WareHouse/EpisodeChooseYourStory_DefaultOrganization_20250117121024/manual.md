# Interactive Storytelling Game

Welcome to the Interactive Storytelling Game! This application allows players to immerse themselves in a dynamic narrative where their choices shape the story's outcome. With branching paths and variable tracking, each decision you make influences the journey and its conclusion.

## Main Functions

- **Narrative Segments**: Experience different parts of the story through narrative segments that present the plot and choices.
- **Branching Choices**: Make decisions that lead to different story paths and outcomes.
- **Variable Tracking**: Track relationships and items that affect the story's progression and possible endings.
- **Graphical User Interface (GUI)**: Interact with the game through a user-friendly interface built with Tkinter.

## Installation

### Prerequisites

Ensure you have Python installed on your system. You can download it from [python.org](https://www.python.org/downloads/).

### Environment Setup

1. **Clone the Repository**: Clone the project repository to your local machine.
   ```bash
   git clone <repository-url>
   ```

2. **Navigate to the Project Directory**: Change into the project directory.
   ```bash
   cd interactive-storytelling-game
   ```

3. **Install Dependencies**: Install the required Python packages using pip.
   ```bash
   pip install -r requirements.txt
   ```

   Ensure your `requirements.txt` file includes:
   ```
   tkinter
   ```

   Note: Tkinter is usually included with Python installations, but you may need to install it separately depending on your system.

## How to Play

1. **Start the Game**: Run the main script to launch the game.
   ```bash
   python main.py
   ```

2. **Interact with the Story**: Use the GUI to read narrative segments and make choices. Each choice will lead to a new segment of the story.

3. **Explore Different Paths**: Experiment with different choices to see how they affect the story and its ending.

4. **Track Your Progress**: The game keeps track of relationships and items, which can influence future segments and the story's conclusion.

## Additional Information

- **Customization**: You can expand the story by adding new narrative segments and choices in the `game_state.py` file.
- **Support**: For any issues or questions, please contact our support team.

Enjoy your adventure in the Interactive Storytelling Game!
