## Introduction

The Blackjack Game is a Python-based application that simulates the classic card game of Blackjack, also known as 21. The game follows standard rules where the dealer hits up to 16 and stands on 17 or above. Players can choose to 'hit,' 'stand,' or 'double down' when appropriate. The game tracks totals, detects busts, and determines the winner after each round.

## Installation

### Prerequisites

- Ensure you have Python installed on your system. You can download it from [python.org](https://www.python.org/downloads/).

### Quick Install

1. **Clone the Repository:**

   Clone the repository to your local machine using the following command:

   ```bash
   git clone <repository-url>
   ```

2. **Navigate to the Project Directory:**

   ```bash
   cd <repository-directory>
   ```

3. **Install Dependencies:**

   The game does not require any external dependencies. However, ensure you have Tkinter installed, which is included with most Python installations.

4. **Run the Game:**

   Execute the following command to start the game:

   ```bash
   python main.py
   ```

## How to Play

1. **Start a New Game:**

   Launch the application by running `main.py`. The game window will open, displaying the player's and dealer's hands.

2. **Player Actions:**

   - **Hit:** Click the "Hit" button to draw another card.
   - **Stand:** Click the "Stand" button to end your turn and let the dealer play.
   - **Double Down:** Click the "Double Down" button to double your bet and receive one final card.

3. **Game Outcome:**

   The game will automatically determine the winner after each round based on the standard Blackjack rules. The result will be displayed on the screen.

## Game Features

- **Graphical User Interface:** The game features a simple and intuitive GUI built with Tkinter.
- **Standard Blackjack Rules:** The dealer hits up to 16 and stands on 17 or above.
- **Player Options:** Players can choose to 'hit,' 'stand,' or 'double down.'
- **Automatic Winner Determination:** The game tracks totals, detects busts, and determines the winner after each round.

## Troubleshooting

- **Tkinter Issues:** If you encounter issues with Tkinter, ensure it is installed correctly. On some systems, you may need to install it separately.
- **Python Version:** Ensure you are using a compatible version of Python. The game is developed and tested with Python 3.x.
