# NYT Connections Puzzle Game

Welcome to the NYT Connections Puzzle Game! This game challenges you to group sixteen words into four categories of four words each, following the standard logic of the NYT Connections game. After each guess, the game will indicate if the chosen words form a valid group. The game ends when you form all four correct groups or run out of tries.

## Main Functions

- **Word Grouping**: Select words to form groups. The goal is to correctly identify all four categories.
- **Feedback System**: After selecting four words, receive immediate feedback on whether the group is correct.
- **Game Over Conditions**: The game concludes when all categories are found or when the maximum number of tries is reached.

## Installation

### Environment Setup

This game is developed in Python and uses the Tkinter library for the graphical user interface. Tkinter is included with Python, so no additional installations are required.

### Quick Install

1. **Clone the Repository**: Download the game files to your local machine.

2. **Navigate to the Game Directory**: Open a terminal and navigate to the directory containing the game files.

3. **Run the Game**: Execute the following command to start the game:
   ```bash
   python main.py
   ```

## How to Play

1. **Launch the Game**: Run the `main.py` file to start the game. A window will open displaying all sixteen words.

2. **Select Words**: Click on words to select them. Selected words will appear sunken to indicate they are chosen.

3. **Form Groups**: Once four words are selected, the game will automatically check if they form a valid category.

4. **Receive Feedback**: If the group is correct, a message will display the category found. If incorrect, you will be notified.

5. **Continue Playing**: Keep selecting words to form groups until all categories are found or you run out of tries.

6. **Game Over**: The game ends when you successfully find all categories or reach the maximum number of tries. A message will display your result.

## Requirements

The game does not require any external dependencies beyond Python and Tkinter, which is included with Python installations.

## Additional Information

- **Tries**: You have a maximum of 10 tries to find all categories.
- **Categories**: The words are grouped into the following categories: fruits, vegetables, animals, and colors.
