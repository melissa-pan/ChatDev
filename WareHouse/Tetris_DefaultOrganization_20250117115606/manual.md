# Tetris Game

Welcome to the Tetris Game! This classic game of falling blocks is designed to challenge your strategic thinking and reflexes. This user manual will guide you through the installation process, introduce the main features of the game, and provide instructions on how to play.

## Quick Install

To get started with the Tetris Game, you need to install the necessary environment dependencies. Follow these steps:

1. **Install Python**: Ensure you have Python installed on your system. You can download it from [python.org](https://www.python.org/downloads/).

2. **Install Pygame**: Pygame is a set of Python modules designed for writing video games. Install it using pip:

   ```bash
   pip install pygame==2.1.2
   ```

3. **Download the Game Code**: Clone or download the game code from the repository.

4. **Run the Game**: Navigate to the directory containing the game code and run the main script:

   ```bash
   python main.py
   ```

## Main Functions of the Software

The Tetris Game includes several key features:

- **Tetromino Movement**: Players can move tetrominoes left, right, and down. They can also rotate the tetrominoes to fit them into the desired position on the board.

- **Line Clearing**: Completed lines are automatically cleared from the board, and the player's score increases accordingly.

- **Game Over Condition**: The game ends when no more tetrominoes can be placed on the board.

- **Score Tracking**: The game keeps track of the player's score, which increases as lines are cleared.

## How to Play

1. **Start the Game**: Launch the game by running the `main.py` script. The game window will open, displaying the Tetris board.

2. **Control the Tetrominoes**:
   - Use the **Left Arrow Key** to move the tetromino left.
   - Use the **Right Arrow Key** to move the tetromino right.
   - Use the **Down Arrow Key** to move the tetromino down faster.
   - Use the **Up Arrow Key** to rotate the tetromino.

3. **Clear Lines**: Arrange the tetrominoes to form complete horizontal lines. When a line is completed, it will be cleared, and your score will increase.

4. **Game Over**: The game ends when a new tetromino cannot be placed on the board. A "Game Over" message will be displayed.

5. **Restart**: To play again, simply close the game window and run the `main.py` script again.

Enjoy the game and aim for the highest score!

## Additional Information

For any issues or questions, please refer to the documentation or contact support. We hope you enjoy playing the Tetris Game and challenge yourself to beat your high score!
