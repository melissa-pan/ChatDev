# Flappy Bird Clone

Welcome to the Flappy Bird Clone, a fun and addictive game where you control a bird trying to fly through a series of pipes without crashing. This game is developed using Python and the Pygame library.

## Main Functions

- **Flap the Bird**: Press the spacebar to make the bird flap its wings and stay airborne.
- **Avoid the Pipes**: Navigate through randomly generated vertical gaps in the pipes.
- **Score Points**: Each successful pass through the pipes increases your score.
- **Game Over**: The game ends if the bird collides with a pipe or the ground.

## Quick Install

To get started with the Flappy Bird Clone, you need to install the necessary environment dependencies. Follow these steps:

1. **Clone the Repository**: Download the source code from the repository.

2. **Install Pygame**: Ensure you have Python installed on your system. Then, install the Pygame library using pip:

   ```bash
   pip install pygame>=2.0.0
   ```

3. **Run the Game**: Navigate to the directory containing the source code and execute the main game file:

   ```bash
   python main.py
   ```

## How to Play

1. **Start the Game**: Run the `main.py` file to start the game. The game window will open, displaying the bird and the first set of pipes.

2. **Control the Bird**: Use the spacebar to make the bird flap its wings. Each press of the spacebar gives the bird an upward thrust.

3. **Navigate the Pipes**: Guide the bird through the gaps in the pipes. The pipes move from right to left, and the gaps are randomly generated.

4. **Score Points**: Each time the bird successfully passes through a set of pipes, your score increases by one.

5. **Game Over**: The game ends if the bird hits a pipe or the ground. Your final score will be displayed on the screen.

6. **Restart**: To play again, simply close the game window and run `main.py` again.

## Additional Information

- **Graphics**: The game features simple graphics with a yellow bird and green pipes against a sky-blue background.
- **Sound**: You can enhance the game by adding sound effects in the `utils.py` file.
- **Customization**: Feel free to modify the code to change the bird's appearance, pipe colors, or game mechanics.

Enjoy playing the Flappy Bird Clone and challenge yourself to achieve the highest score possible!
