# Tic-Tac-Toe Game

Welcome to the Tic-Tac-Toe Game! This application allows two players to engage in a classic game of Tic-Tac-Toe with a user-friendly graphical interface.

## Main Functions

- **Two-Player Mode**: The game allows two players to take turns playing as 'X' and 'O'.
- **Winner Determination**: The game automatically checks for a winner after each move and announces the result.
- **Draw Detection**: If all positions are filled and no player has won, the game declares a draw.
- **Reset Functionality**: Players can reset the game at any time to start a new match.

## Installation

### Prerequisites

- Ensure you have Python 3.x installed on your system.
- The game requires the `tkinter` library, which is included with most Python installations. If not, you may need to install it separately.

### Installation Steps

1. **Clone the Repository**: Download the source code from the repository or copy the `main.py` file to your local machine.

2. **Install Dependencies**: 
   - Since the game uses `tkinter`, ensure your Python environment supports it. Typically, no additional installation is required for `tkinter` if you have Python installed.

3. **Run the Game**: 
   - Navigate to the directory containing `main.py` and execute the following command in your terminal or command prompt:
     ```bash
     python main.py
     ```

## How to Play

1. **Start the Game**: Launch the game by running `main.py`. A window will open displaying the Tic-Tac-Toe board.

2. **Make a Move**: 
   - Player 'X' starts the game. Click on any empty button on the grid to make a move.
   - The game will automatically switch turns between Player 'X' and Player 'O'.

3. **Check for Winner**: 
   - The game will notify you if a player wins or if the game ends in a draw.

4. **Reset the Game**: 
   - Click the 'Reset' button to clear the board and start a new game.

## Additional Information

- **User Interface**: The game uses a simple graphical interface with buttons representing each cell on the Tic-Tac-Toe board.
- **Game Logic**: The game checks for winning conditions after each move and updates the interface accordingly.

Enjoy playing Tic-Tac-Toe with your friends and family!
