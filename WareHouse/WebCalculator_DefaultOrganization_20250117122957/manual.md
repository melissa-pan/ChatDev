# Responsive Web-Based Calculator

Welcome to the user manual for the Responsive Web-Based Calculator. This document will guide you through the main functions of the calculator, how to set up your environment, and how to use the calculator effectively.

## Introduction

The Responsive Web-Based Calculator is a simple, intuitive tool designed to perform basic arithmetic operations. It features a numeric keypad and supports addition, subtraction, multiplication, and division. The calculator is designed with a clean user interface that adapts to various screen sizes, making it accessible on both desktop and mobile devices.

## Main Functions

- **Numeric Keypad**: Allows users to input numbers for calculations.
- **Basic Operations**: Supports addition (+), subtraction (-), multiplication (*), and division (/).
- **Display Area**: Shows the current input and results of calculations.
- **Clear Function**: Resets the calculator to its initial state.

## Installation

To use the calculator, you need to set up a simple web environment. Follow these steps:

1. **Download the Files**: Ensure you have the following files:
   - `index.html`: Contains the structure of the calculator.
   - `styles.css`: Provides the styling for the calculator.
   - `script.js`: Contains the logic for calculator operations.

2. **Set Up a Local Server**: You can use any local server setup, such as:
   - **Using Python**: Run `python -m http.server` in the directory containing your files.
   - **Using Node.js**: Use a package like `http-server` to serve your files.

3. **Open in Browser**: Once your server is running, open a web browser and navigate to `http://localhost:8000` (or the appropriate port) to view the calculator.

## How to Use

1. **Launch the Calculator**: Open the calculator in your web browser.

2. **Input Numbers**: Click on the numeric buttons to input numbers. The numbers will appear in the display area.

3. **Perform Operations**: Click on the operation buttons (+, -, *, /) to perform calculations. You can chain operations by entering a new number and selecting another operation.

4. **Compute Result**: Click the `=` button to compute the result of the current operation. The result will be displayed in the display area.

5. **Clear Display**: Click the `C` button to clear the current input and reset the calculator.

## Responsive Design

The calculator is designed to be responsive, ensuring it works seamlessly on various screen sizes. The layout adjusts to fit smaller screens, making it easy to use on mobile devices.
