# Trivia Quiz Program

Welcome to the Trivia Quiz Program! This application is designed to provide an engaging and interactive quiz experience, where users can answer multiple-choice questions on various topics and track their scores.

## Main Functions

- **Interactive Quiz Interface**: The program presents questions one at a time, allowing users to select their answers through a graphical user interface.
- **Score Tracking**: The application keeps track of the user's score, updating it based on correct answers.
- **Final Score Display**: At the end of the quiz, the program displays the total number of correct answers out of the total questions.

## Installation

### Environment Setup

The Trivia Quiz Program is developed in Python and utilizes the Tkinter library for its graphical user interface. Tkinter is part of the Python standard library, so no additional dependencies are required.

### Steps to Install

1. **Ensure Python is Installed**: Make sure you have Python installed on your system. You can download it from [python.org](https://www.python.org/downloads/).

2. **Clone the Repository**: Download or clone the source code to your local machine.

3. **Run the Application**: Navigate to the directory containing the `main.py` file and execute the following command in your terminal or command prompt:

   ```bash
   python main.py
   ```

   This will launch the Trivia Quiz application.

## How to Use/Play

1. **Start the Quiz**: Upon launching the application, the first question will be displayed on the screen.

2. **Answer Questions**: Select the correct answer by clicking on one of the provided options. The program will immediately inform you if your choice was correct or incorrect.

3. **Proceed to Next Question**: Click the "Next" button to move to the following question.

4. **Complete the Quiz**: After answering all questions, the application will display your total score, showing how many questions you answered correctly out of the total number of questions.

5. **End of Quiz**: Once the quiz is finished, the buttons will be disabled, indicating the end of the session.

Enjoy testing your knowledge with the Trivia Quiz Program!
