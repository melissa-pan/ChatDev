## Introduction

The Pong Game is a simple yet engaging two-player game where each player controls a vertical paddle. The objective is to bounce the ball back and forth, scoring points when the opponent misses the ball. The game is built using Python and the Pygame library, providing a smooth and interactive gaming experience.

## Installation

To play the Pong Game, you need to have Python and Pygame installed on your system. Follow the steps below to set up your environment:

### Step 1: Install Python

Ensure you have Python installed on your system. You can download it from the [official Python website](https://www.python.org/downloads/).

### Step 2: Install Pygame

Once Python is installed, you can install Pygame using pip. Open your command line interface and run the following command:

```bash
pip install pygame==2.1.2
```

### Step 3: Download the Game Files

Download the game files from the provided source or repository. Ensure that you have the following files:

- `main.py`
- `paddle.py`
- `ball.py`
- `score.py`
- `requirements.txt`

## Game Features

- **Two-Player Mode**: Engage in a competitive match with a friend.
- **Realistic Physics**: The ball bounces off paddles and walls, simulating real-world physics.
- **Score Tracking**: Keep track of each player's score displayed at the top of the screen.
- **Simple Controls**: Easy-to-use keyboard controls for both players.

## How to Play

1. **Start the Game**: Run the `main.py` file to start the game. You can do this by navigating to the directory containing the game files and executing the following command in your terminal:

    ```bash
    python main.py
    ```

2. **Game Controls**:
   - **Player 1**: Use the `W` key to move the paddle up and the `S` key to move it down.
   - **Player 2**: Use the `UP` arrow key to move the paddle up and the `DOWN` arrow key to move it down.

3. **Objective**: Bounce the ball back and forth using your paddle. Score a point when your opponent misses the ball.

4. **Winning the Game**: The game continues until you decide to quit. Keep track of your scores and challenge your opponent to beat your high score!

## Troubleshooting

- **Pygame Installation Issues**: Ensure you have the correct version of Python and Pygame installed. Refer to the installation section for guidance.
- **Game Not Starting**: Check if all game files are in the same directory and that you are running the `main.py` file.
- **Controls Not Working**: Make sure your keyboard is functioning properly and that the game window is active when pressing keys.

Enjoy playing the Pong Game and may the best player win! If you encounter any issues or have suggestions, feel free to reach out to our support team.
